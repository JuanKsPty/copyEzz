# Cambios

## 0.2.0

- Contexto: sube un `.txt` con apuntes, el temario o un banco de preguntas (desde la página con **+ contexto .txt** o en Ajustes) y el modelo responde con ese material. Funciona con los tres motores, se conserva al reiniciar y se quita con ×.
- Cada respuesta indica con qué archivo de contexto se respondió.

## 0.1.1

- Las actualizaciones encontradas en segundo plano se avisan en el menú ("⬆︎ Instalar CopyEzz …") en vez de abrir una ventana en medio de otra cosa.

## 0.1.0

- Primera versión nativa: app de barra de menú que reemplaza al server Python + Hammerspoon.
- Disparo con el botón lateral del mouse (por defecto el 4, "adelante") o ⌃⌥⌘A, configurables.
- Motores: Claude Code (tu suscripción), API de Anthropic (key en el Llavero) y Ollama local.
- La respuesta aparece en el título de la pestaña http://127.0.0.1:8765 y, si lo activas, en la barra de menú.
- Abrir al iniciar sesión y actualizaciones automáticas con Sparkle.
