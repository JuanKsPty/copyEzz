# CopyEzz

App de barra de menú para macOS: un botón del mouse (o ⌃⌥⌘A) captura la pantalla, un modelo de visión resuelve la pregunta de quiz visible y la respuesta aparece en el título de la pestaña `http://127.0.0.1:8765`.

> En construcción: migrando de la versión Python + Hammerspoon (`legacy/`) a una app nativa.
